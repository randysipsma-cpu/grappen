# NIKS AAN DE HAND!\n\nPWA met 30 Nederlandse cartoon-grappen en een iPhone-deelknop.\n\nGitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).\n\nOpen daarna https://randysipsma-cpu.github.io/grappen/ in Safari en kies Deel → Zet op beginscherm.\n\nDeelknop vraagt bevestiging op privé-Facebook. Facebook neemt bijschriften mogelijk niet automatisch over; kopieer tekst apart.\n\nDeze online versie gebruikt één getekend stripfiguur in de app en maakt deelafbeeldingen met illustratieve emoji en bijschriften. De eerder gemaakte 30 losse SVG-bestanden zijn nog niet geüpload.
